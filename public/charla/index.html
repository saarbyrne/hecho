How it works

1

Pick themes.

Choose the themes you like, such as food, travel or football. Each theme has five questions for you.

2

Talk.

charla asks the questions out loud, one by one. Say «siguiente pregunta» for the next.

3

Remember.

charla saves a summary of each session, and a theme comes back later with new questions.

Set up

Ready in
two minutes.

charla talks through Google Gemini, so you need a free key from Google. No card is needed.

  1. Go to aistudio.google.com/apikey and sign in with Google.
  2. Accept the terms if asked, then click Create API key.
  3. Copy the key. It is a long code that starts with AIza.
  4. Open charla, paste the key into Clave de Gemini and click Guardar.
  5. Allow the microphone and start talking.

The key is saved only in your browser. On a phone, add charla to your Home Screen.

Questions

Is it free?
Yes. Google's free Gemini tier covers it, with rate limits that Google sets.
Does Google use my conversations?
Not in the EEA, the UK or Switzerland. Elsewhere, free-tier conversations can be used to improve Google's products.
How long is a session?
Up to 15 minutes. Gemini ends audio sessions after that.
